SVG

One <circle> DOM element per point. Inspect or style points individually.

Hover over a point

Canvas 2D

JavaScript paints points into a bitmap. Individual points are not DOM elements.

Updating a point requires drawing again.

WebGL

GPU draws points using buffers and shaders. No per-point DOM elements.
